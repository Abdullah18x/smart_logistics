Fastest way to see it running

  1. Install Docker Desktop and uv, then from the repository root: ./dev.sh docker up (Windows: dev docker up)
  2. Load sample data: ./dev.sh docker seed
  3. Open http://localhost:8000/docs — one Swagger UI for every service, generated from the code. Pick a service in the top-right dropdown.
Log in with admin@transfleet.com / SmartLogistics!2026, or one of the other 10 seeded accounts (support, warehouse operators, couriers) to see what each role can and cannot do. For day-to-day coding, run the services on your machine instead: ./dev.sh infra up then ./dev.sh start --reload.
